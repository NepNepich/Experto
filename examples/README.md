Примечание MVP: Авторизация упрощена. Сервер возвращает user_id, который фронтенд хранит в localStorage/состоянии. В продакшене он будет заменён на JWT-токен.

примеры (.py файлы) сделал по большей части иишкой, чтобы показать, что она может работать с апи на случай, если разработчикам понадобится генерировать код (нехватка времени и прочее)

`add-test-data.py` Заполнение БД тестовыми данными 
`example-web-org.py` Организатор, Веб, Создание проектов, управление правами, дашборд, экспорт. csv выгружается в корневую папку модуля, не в examples
`example-web-student.py` Студент, Веб, Просмотр своих работ, фидбек (Режим 1/2) 
`example-bot-expert.py` Эксперт, Бот (Режим 1), Взять работу → оценить → финализировать → авто-выдача 
`example-bot-student-2.py` Студент, Бот (Режим 2), Взять работу, написать комментарий, финализировать 

все скрипты используют авторизацию по email (`/auth/web`). Поле `telegram_id` игнорируется, но сохранено в коде для будущей интеграции с ботом.

`example-web-student.py`

`example-bot-expert.py`
Имитирует поток эксперта в боте: взять работу, оценить, финализировать, получить следующую.

1. Авторизуется как exp2@test.com
2. Находит активный проект Режима 1
